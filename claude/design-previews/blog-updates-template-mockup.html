Short answer

A core update changes how Google ranks pages across all topics. Do not make big changes while it rolls out. Note your rankings now, wait until Google says it is complete, then compare and fix pages that dropped.

In depth

How core updates work

Core updates are broad changes to how Google judges content. They are not aimed at one site or one tactic, which is why there is no single fix. Pages that drop usually need to be more useful than the pages that now rank above them.

Questions

FAQs

Should I change my site during a core update?

Avoid big changes until the rollout is complete, so you can see what the update did on its own.

How long do core updates take?

Google usually says when an update starts and when it is complete. Past core updates have taken about two weeks.
