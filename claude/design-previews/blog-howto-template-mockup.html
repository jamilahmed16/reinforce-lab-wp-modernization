How to check whether Google has indexed a page

Find out in a few minutes whether a page is in Google's index, why it might not be, and what to fix before you ask Google to look again.

    Short answer

    Paste the full URL into the URL Inspection tool in Google Search Console. It tells you whether the page is on Google, when Google last crawled it, and which URL Google treats as the main version. A site: search is not a reliable check.

    Google keeps only some of the pages it finds. A page can be crawled and still left out, or kept under a different URL than the one you expect. These five steps find out which, using free tools.

    1

    Step 1 of 5 · 3 min

    Open the URL Inspection tool

    Why: it is the only check that reads Google's own record of the page.

    1. Sign in to Google Search Console and pick the property that contains the page.
    2. Click the search bar at the top, labelled "Inspect any URL".
    3. Paste the full URL and press Enter.
    You should seeA report titled "URL Inspection" with either "URL is on Google" or "URL is not on Google".
    2

    Step 2 of 5 · 3 min

    Read the indexing status

    Why: the status tells you which of the next steps you need.

    If the report says URL is on Google, the page is indexed and you can stop here. If it says URL is not on Google, open the "Page indexing" section to see the reason.

    You should seeA reason such as "Crawled, currently not indexed" or "Excluded by noindex tag".

    3

    Step 3 of 5 · 4 min

    Compare the canonical URLs

    Why: Google may be indexing a different version of the page.

    Under "Page indexing", compare User-declared canonical with Google-selected canonical. If they differ, Google treats another URL as the main version.

    You should seeBoth lines showing the same URL. If not, note the URL Google chose.
    4

    Step 4 of 5 · 3 min

    Fix the cause

    Why: asking Google to look again changes nothing until the cause is gone.

    Remove a noindex rule you did not intend, unblock the page in robots.txt, or point the canonical to the right URL. Thin or duplicate pages need better content.

    5

    Step 5 of 5 · 2 min

    Request indexing

    Why: it asks Google to crawl the fixed page sooner.

    Run "Test live URL" first to confirm the fix, then click Request indexing.

    You should see"Indexing requested". It does not guarantee indexing, and timing varies.

    Done: you know where the page stands

    Check the URL again in a week. If it is still not indexed, look at whether the page offers something the indexed pages on the topic do not.

    Your progress

    0 of 5 steps done

    Avoid these

    • Relying on a site: search. It is a rough guide, not a record.
    • Requesting indexing before you fix the cause.
    • Inspecting the wrong property, such as http instead of https.

    If something goes wrong

    "Request indexing" is greyed out

    You need owner or full user access to the property. Ask the owner to add you.

    "URL is not in property"

    The URL belongs to a different property. Check the domain, protocol and www.

    The live test passes but the page is still not indexed

    Indexing is not guaranteed. Improve the page and check again in a week.

    Questions

    FAQs

    How long does indexing take?

    It varies by site and page. Requesting indexing can speed up a recrawl, but it does not guarantee indexing.

    Does a site: search show every indexed page?

    No. Use Search Console for a reliable answer.
