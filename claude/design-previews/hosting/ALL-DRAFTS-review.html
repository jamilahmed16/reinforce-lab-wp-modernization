What is the Cloudways MCP server?

MCP stands for Model Context Protocol. It is a standard way for AI tools to connect to other software. Cloudways says its MCP server connects your AI assistant to your Cloudways account and turns your requests into real actions on your servers and apps.

What can it do?

Cloudways lists tools for account, server, app, service, monitoring, DNS, Cloudflare, Git and security tasks. Examples from the help article:

How do you set it up?

  1. Get credentials. Log in to the Cloudways platform and open API Integration from your profile. Cloudways says the old API key method is deprecated by 15 October 2026 and tells you to use an access token instead.
  2. Add the server to your AI client. The MCP address is https://mcp.cloudways.com/mcp/. Each request needs two headers, X-Access-Token and X-Mcp-Host. The help article has steps for Cursor, Claude Desktop, Claude Code, VS Code, Gemini CLI and Codex.
  3. Check the link. Ask "Show me all my servers". You should see your servers with their status, provider, region and IP address.

What do you need?

  • A Cloudways account with access to the servers you want to manage.
  • An MCP-compatible AI client.
  • Node.js 24.14.1 or higher for some clients, such as the Claude Desktop bridge.
