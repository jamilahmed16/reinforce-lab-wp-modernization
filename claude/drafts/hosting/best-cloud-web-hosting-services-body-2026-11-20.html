What is cloud hosting?

Cloud hosting runs your site on a network of connected servers instead of one machine. HostingAdvice says this improves reliability, uptime and flexibility compared with shared or VPS hosting. In practice, you buy a set amount of CPU and memory on that network, and many hosts let you add more when traffic grows.

Managed or unmanaged cloud hosting?

Managed means the host updates the server, sets up caching and watches security. Cloudways, Kinsta, ScalaHosting, SiteGround Cloud and Liquid Web do this to different degrees. Unmanaged means you do it. DigitalOcean is the clearest example: the price is low, and the server is yours to look after.

Is cloud hosting faster and safer than shared hosting?

Not by itself. A cloud plan with enough CPU and memory holds up better under load, which is why several tests above use many concurrent users. But a slow site stays slow without caching. On a $6 DigitalOcean Droplet, a page cache cut first-byte time from 1.66 seconds to 0.40 seconds. On safety, managed hosts add firewalls, patching and backups. SiteGround Cloud lists a firewall with WordPress rules, and Kinsta lists daily backups. On an unmanaged server you add these yourself.

How do you move a site to cloud hosting?

  • Back up the site and the database before you start.
  • Choose a server region near your visitors.
  • Copy the files and database, or use the host's free migration. Kinsta, Liquid Web and Hostinger list free migration, and SiteGround lists a migrator plugin.
  • Test the new site on a temporary address and check every form and checkout.
  • Lower the domain's TTL a day ahead, then switch the domain and watch for errors.

A move that changes URLs or loses redirects can cost rankings. If you want the move done and checked for you, see our website maintenance services.

Cloud hosting vs VPS: which is better?

The two overlap, and many providers sell VPS plans on cloud servers, so the names blur. The simple difference is this. A VPS gives you a fixed slice of one server. Cloud hosting runs your site on a network of servers, so it is easier to grow and to recover if one machine fails. Hostinger says its cloud plans sit in the middle: more resources than shared hosting, and less control than a VPS. Choose a VPS if you want full control and can run a server. Choose managed cloud if you want the speed without the server chores.

Cloud hosting vs shared hosting: what do you gain?

Shared hosting puts many sites on one server for a fixed price. Cloud hosting gives your site its own slice of resources. Expertah says this is the main reason people move to Cloudways: busy WordPress sites and stores usually run more smoothly on dedicated resources than on cheap shared hosting. The trade-off is cost. Shared plans start near $2 a month, while managed cloud starts near $11. A small site does not need to move.

What is unmanaged cloud hosting?

Unmanaged means the host gives you the server and you run it. You install updates, set up security and caching, and take backups. It costs less and gives full control, but it needs skill. DigitalOcean is the example on this list: a page cache cut first-byte time from 1.66 to 0.40 seconds on a $6 Droplet, and backups add 20% to 30%. If you are not comfortable with a terminal, pick a managed host.

Which cloud hosting providers run the servers?

Most cloud hosts sit on top of a few big infrastructure providers. Cloudways lets you choose DigitalOcean, Vultr, Linode, AWS or Google Cloud for each server. DigitalOcean runs its own cloud. ScalaHosting lists data centers in Dallas, New York and Sofia plus AWS. Pick a location close to your visitors, because distance changes the first-byte time.

What should you check before you buy cloud hosting?

  • CPU cores and memory. These set how many pages the server can build at the same time. HostingGuider compares plans by cores and RAM for this reason.
  • The term and renewal price. Write both down before you pay.
  • Where the server is. HostingGuider's Singapore server answered in 157 ms from Singapore and 674 ms from Sydney. Choose a region near your visitors.
  • Backups. Check how many days are kept and whether they cost extra.
  • Who you can reach. Kinsta and SiteGround Cloud list human support. DigitalOcean charges for chat.
  • Card payments. Hostinger is not PCI compliant. Check how your payment provider handles it.
